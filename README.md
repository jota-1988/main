# Jota 1988 — website

Versión estática preparada para GitHub Pages.

## Publicar

1. Creá un repositorio nuevo en GitHub.
2. Subí **el contenido de esta carpeta** a la raíz del repositorio.
3. Entrá en **Settings → Pages**.
4. En **Build and deployment**, elegí **Deploy from a branch**.
5. Seleccioná la rama **main**, carpeta **/(root)** y guardá.

La web no necesita instalar dependencias ni ejecutar ningún build.
